# Vietnam Culinary Adventure — Full Platform Prototype

Mobile-first frontend prototype for a culinary tour operator in Saigon, Da Nang and Hanoi.

## Run
Open `index.html` in a modern browser. External images/fonts require internet access.

## Prototype modules
- Destination navigation and city filtering
- Tour catalogue and tour detail modal
- Booking enquiry form
- Demo booking list in the Admin section

## Production work still required
This repository is a frontend prototype, not a production booking platform. Enquiries are stored only in the current browser's localStorage. Add a secure backend/database, admin authentication and role permissions, availability/inventory, email/WhatsApp notifications, payment gateway, privacy/terms, server-side validation, backups, logging and deployment configuration before accepting real bookings.
